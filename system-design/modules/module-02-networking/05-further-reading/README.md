# Module 02 — Further Reading

- **"High Performance Browser Networking" by Ilya Grigorik** (hpbn.co, free online) — the definitive deep dive on TCP, TLS, HTTP/1.1, HTTP/2, and WebSockets from a performance perspective.
- **Cloudflare Learning Center — "What is DNS?"** (cloudflare.com/learning/dns) — a clear, vendor-neutral explanation of DNS resolution with good diagrams.
- **RFC 9114 — HTTP/3** (datatracker.ietf.org/doc/html/rfc9114) — the actual specification, useful once you want more precision than a survey article gives.
- **"It's Time to Move on from QUIC vs TCP debates" and related QUIC explainers from the Cloudflare and Fastly engineering blogs** — practical, production-informed perspectives on HTTP/3 adoption trade-offs.
- **MDN Web Docs — "Server-sent events"** (developer.mozilla.org) — concise reference for the SSE API and protocol format.
