# Module 17 — Further Reading

- **"MapReduce: Simplified Data Processing on Large Clusters" (Dean & Ghemawat — Google, OSDI 2004)** — the original MapReduce paper. Short, foundational, and the direct conceptual ancestor of Hadoop and, by extension, Spark's batch model; essential for understanding why the map/reduce split and automatic fault-tolerant scheduling were the breakthrough.
- **Apache Spark — Official Documentation** (spark.apache.org/docs/latest) — the canonical reference for Spark's RDD/DataFrame APIs, its DAG-based execution model, and how in-memory computation across stages improves on classic disk-based MapReduce.
- **Apache Kafka — Official Documentation, "Kafka Streams" section** (kafka.apache.org/documentation/streams) — the official guide to Kafka Streams' DSL, its embedding model (a library, not a separate cluster), and exactly-once processing semantics.
- **Apache Flink — Official Documentation** (nightlies.apache.org/flink/flink-docs-stable, or flink.apache.org) — the canonical reference for Flink's event-time processing, watermarks, windowing, and checkpointing model referenced throughout this module's deep dive.
- **"How to beat the CAP theorem" and the Lambda Architecture writeups (Nathan Marz, nathanmarz.com / the "Big Data" book by Marz & Warren)** — Nathan Marz's original articulation of the Lambda architecture (batch layer + speed layer + serving layer), written while he was building Storm at Twitter/BackType; the primary source for the architecture this module covers.
- **"Questioning the Lambda Architecture" (Jay Kreps, oreilly.com/radar, 2014)** — Jay Kreps' (Kafka co-creator) article proposing the Kappa architecture as a simplification of Lambda, arguing that a sufficiently durable, replayable log makes a separate batch layer unnecessary for many use cases. The primary source for the Kappa architecture covered in this module.
- **Debezium — Official Documentation** (debezium.io/documentation) — the canonical reference for how Debezium's connectors tail database transaction logs (PostgreSQL WAL, MySQL binlog, and others) and convert committed changes into Kafka events; includes the exact change-event JSON structure this module's CDC simulator is modeled after.
- **Apache Parquet — Documentation and Format Specification** (parquet.apache.org) — the official documentation and on-disk format specification for Parquet, including how column chunks, row groups, and per-column statistics (used for predicate pushdown) are laid out.
- **Apache ORC — Documentation** (orc.apache.org) — the official documentation for the ORC columnar format, useful as a second real-world columnar format to compare against Parquet, including its built-in indexes and compression options.
- **Apache Airflow — Official Documentation** (airflow.apache.org/docs) — the canonical reference for defining DAGs in Python, the scheduler's execution model, task retries/alerting, and the operator ecosystem (how Airflow tasks trigger external systems like Spark or a data warehouse).
- **Apache Iceberg — Documentation** (iceberg.apache.org/docs/latest) — the official documentation for Iceberg's table format, a leading open implementation of the "lakehouse" transactional metadata layer discussed in this module's deep dive, including its approach to schema evolution and time travel.
