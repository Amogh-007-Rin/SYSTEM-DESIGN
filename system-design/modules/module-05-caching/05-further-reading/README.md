# Module 05 — Further Reading

- **Redis official documentation — "Data Types"** (redis.io/docs/data-types) — the authoritative reference for strings, hashes, sets, sorted sets, and bitmaps.
- **"Scaling Memcache at Facebook" (Nishtala et al., 2013)** — a real production paper on operating a distributed cache at enormous scale, including thundering herd mitigations.
- **Twitter Engineering Blog — caching and timeline architecture posts** — practical, production-grade discussion of fan-out and feed caching at the exact scale this module's examples are modeled on.
- **"Cache Invalidation Strategies" — various engineering blogs (Cloudflare, Fastly)** — CDN providers write extensively and practically about invalidation since it's core to their product.
- **Bloom Filters — original paper: "Space/Time Trade-offs in Hash Coding with Allowable Errors" (Bloom, 1970)** — the original, surprisingly short and readable source.
