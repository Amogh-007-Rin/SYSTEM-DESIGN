# Module 09 — Exercises

> 💡 **Note:** This module has **design challenges only — no coding challenges**. Storage systems are best practiced as architecture-level design exercises (what goes where, and why) rather than as small isolated coding problems; the hands-on coding in this module instead lives in the worked TypeScript examples inside [`01-concepts/examples/`](../01-concepts/examples/) and [`02-deep-dive/examples/`](../02-deep-dive/examples/), which you should make sure you've run and understood before attempting these.

## Design Challenges

| Challenge | Description |
|---|---|
| [01 — Photo Storage System](./design-challenges/challenge-01.md) | Design a photo storage system like Instagram — upload flow, storage backend, CDN integration |
| [02 — Distributed File System Metadata Layer](./design-challenges/challenge-02.md) | Design the metadata layer for a distributed file system in the GFS/HDFS style |

Challenge 01 is answered in full depth in [`03-interview-prep/sample-answer.md`](../03-interview-prep/sample-answer.md) — attempt the challenge yourself first, then compare your answer against it.
