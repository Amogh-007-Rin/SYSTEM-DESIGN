# Module 04 — Further Reading

- **"Designing Data-Intensive Applications" by Martin Kleppmann** — the single best book covering replication, partitioning, and consistency in depth; chapters 5–7 map directly onto this module's deep dive.
- **PostgreSQL official documentation — "Indexes"** (postgresql.org/docs/current/indexes.html) — authoritative reference on B-tree, hash, GIN, and other index types.
- **"Consistent Hashing and Random Trees" (Karger et al., 1997)** — the original academic paper introducing consistent hashing.
- **Amazon's "Dynamo: Amazon's Highly Available Key-value Store" paper** — foundational reading for understanding consistent hashing and quorum-based replication in a real production system (also relevant to [Module 12](../../module-12-distributed-systems/)).
- **Use the Index, Luke!** (use-the-index-luke.com) — a free, practical guide specifically about SQL indexing and query performance.
