# Module 04 — Exercises

## Coding Challenges

| Challenge | Description |
|---|---|
| [01 — Index Performance](./coding-challenges/challenge-01/) | Measure query time with and without an index, using `node:sqlite` |
| [02 — Connection Pool](./coding-challenges/challenge-02/) | Implement a simple connection pool from scratch |
| [03 — Consistent Hashing](./coding-challenges/challenge-03/) | Implement consistent hashing with virtual nodes, the algorithm behind most distributed sharding schemes |

## Design Challenges

| Challenge | Description |
|---|---|
| [01 — Twitter Schema Design](./design-challenges/challenge-01.md) | Design a full schema for tweets, follows, likes, retweets — justify SQL vs. NoSQL |
| [02 — Sharding Strategy for 1B Users](./design-challenges/challenge-02.md) | Design a sharding strategy for a database at billion-user scale |

Challenge 03 (consistent hashing) is the most important exercise in this module — it's referenced again in [Module 12](../../module-12-distributed-systems/) and [Module 20](../../module-20-advanced-patterns/).
