# Module 01 — Foundations of System Design

> Every system you'll ever design is built from the same handful of moving parts and the same handful of trade-offs — learn those once, here, and every later module becomes a variation on a theme.

| Module | Topics Needed |
|---|---|

> 💡 Complete prerequisite modules first — this one builds directly on them.

---

## What You'll Learn

By the end of this module you will be able to:
- Define system design and explain how it differs from software design and software architecture
- Identify the core components of any system (clients, servers, databases, networks) and how they connect
- Reason explicitly about availability, reliability, scalability, maintainability, performance, durability, and consistency as named, measurable properties
- Read and draw a basic system architecture diagram
- Run a back-of-envelope capacity estimation and explain an SLA/SLO/SLI in your own words
