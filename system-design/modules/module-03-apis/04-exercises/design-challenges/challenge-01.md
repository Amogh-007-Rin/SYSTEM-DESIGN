# Design Challenge 01: API Surface for a Ride-Sharing App

**Difficulty:** Medium

## Prompt

Design the API surface for an Uber-like ride-sharing app, covering both the rider and driver sides.

## What to Produce

1. Core actions in plain English (request a ride, driver accepts, track ride, complete ride, rate driver, etc.)
2. Endpoint definitions: method, path, request/response shape, for at least 6 endpoints
3. How you'd model ride status transitions (requested → matched → in-progress → completed) in the API
4. Your pagination strategy for ride history
5. Your versioning strategy and justification
6. How you'd handle the real-time location updates (which protocol, and why — refer back to [Module 02](../../../module-02-networking/01-concepts/README.md))

A full worked solution is at [`challenge-01-solution.md`](./challenge-01-solution.md).
