## Design Challenges

| Challenge | Description |
|---|---|
| [01 — Load Balancing Strategy for a Video Streaming Service](./design-challenges/challenge-01.md) | Design the full load balancing strategy (algorithm, L4 vs L7, HA, global routing) for a video streaming platform |

Challenge 01 (Round Robin / Least Connections) is one of the most commonly asked load-balancing-adjacent coding questions in interviews — make sure you can explain *why* the two algorithms produce different selection sequences, not just implement them.
