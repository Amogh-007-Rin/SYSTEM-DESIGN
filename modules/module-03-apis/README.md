# Module 03 — API Design

> The API is the contract your system makes with the rest of the world — get it wrong and every client of your system inherits the mistake forever.

---

| Module | Topics Needed |

> 💡 Complete prerequisite modules first — this one builds directly on them.

---

## What You'll Learn

By the end of this module you will be able to:
- Design a RESTful API that follows resource-based conventions, with correct HTTP methods and status codes
- Choose between REST, GraphQL, and gRPC for a given use case and justify the choice
- Implement and explain rate limiting algorithms (token bucket, leaky bucket, sliding window)
- Design an API versioning strategy and explain idempotency key usage
- Explain what an API gateway does in a microservices architecture
