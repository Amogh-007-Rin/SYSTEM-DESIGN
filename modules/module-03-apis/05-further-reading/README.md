# Module 03 — Further Reading

- **Stripe API Reference and Documentation** (stripe.com/docs/api) — widely regarded as one of the best-designed public REST APIs in the industry; especially good for idempotency key usage.
- **"REST API Design Rulebook" by Mark Masse** — a concise, practical reference for resource naming and HTTP method usage.
- **GraphQL official documentation** (graphql.org/learn) — the canonical source for schema design, queries, mutations, and subscriptions.
- **gRPC official documentation** (grpc.io/docs) — covers Protocol Buffers and the four RPC types (unary, server streaming, client streaming, bidirectional).
- **OAuth 2.0 RFC 6749** (datatracker.ietf.org/doc/html/rfc6749) — the actual specification; dense but authoritative.
- **"Stripe's Idempotency Keys" engineering documentation** (stripe.com/docs/api/idempotent_requests) — a real-world, production explanation of the idempotency key pattern covered in this module's deep dive.
