# Module 02 — Networking Fundamentals for System Designers

> Every system design decision you'll ever make is downstream of a network call — its latency, its reliability, its protocol. This module gives you just enough networking to reason about those calls without needing a networking degree.

---

## Prerequisites

| Module | Topics Needed |
|---|---|
| [Module 01 — Foundations](../module-01-foundations/) | Vocabulary for clients/servers, the concept of latency vs. throughput |

> 💡 Complete prerequisite modules first — this one builds directly on them.

---

## What You'll Learn

By the end of this module you will be able to:
- Explain how DNS resolves a domain name to an IP address, end to end
- Choose between TCP and UDP for a given use case and justify the choice
- Explain the practical differences between HTTP/1.1, HTTP/2, and HTTP/3
- Choose between WebSockets, SSE, long polling, and short polling for a real-time feature
- Reason about latency budgets using the numbers every engineer should know
