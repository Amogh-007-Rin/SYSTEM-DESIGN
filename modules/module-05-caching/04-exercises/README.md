# Module 05 — Exercises

## Coding Challenges

| Challenge | Description |
|---|---|
| [01 — LRU Cache](./coding-challenges/challenge-01/) | Implement an LRU cache from scratch using a hashmap + doubly-linked list, both O(1) |
| [02 — Cache-Aside Pattern](./coding-challenges/challenge-02/) | Implement cache-aside against a mock database and a Redis-shaped cache client |
| [03 — Bloom Filter](./coding-challenges/challenge-03/) | Implement a Bloom filter to prevent cache penetration |

## Design Challenges

| Challenge | Description |
|---|---|
| [01 — Caching Strategy for a Twitter Feed](./design-challenges/challenge-01.md) | Design a full caching strategy: what to cache, where, eviction, invalidation |

Challenge 01 (LRU) is the most commonly asked caching-adjacent coding question in interviews — make sure you can implement it from memory before moving on.
