# Module 17 — Exercises

> 💡 **Note:** Per this module's specification, this module has **design challenges only — no coding challenges**. Data pipeline architecture is best practiced as system-level design exercises (what processes the data, where it lands, how layers compose) rather than as small isolated coding problems; the hands-on coding for this module instead lives in the worked TypeScript examples inside [`01-concepts/examples/`](../01-concepts/examples/) and [`02-deep-dive/examples/`](../02-deep-dive/examples/), which you should make sure you've run and understood before attempting these.

## Design Challenges

| Challenge | Description |
|---|---|
| [01 — Ride-Sharing Real-Time Analytics](./design-challenges/challenge-01.md) | Design a real-time analytics pipeline for a ride-sharing app: trips per minute, surge pricing triggers, driver availability heatmaps |
| [02 — Fraud Detection Pipeline](./design-challenges/challenge-02.md) | Design a fraud detection pipeline processing 100K transactions/second with sub-500ms latency |

Both challenges are answered in full depth in their respective `-solution.md` files — attempt each challenge yourself first, then compare your answer against the worked solution. A third fully worked example ("Design a real-time data pipeline for clickstream analytics") lives in [`03-interview-prep/sample-answer.md`](../03-interview-prep/sample-answer.md) and is worth reading alongside these two.
