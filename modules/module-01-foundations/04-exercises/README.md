# Module 01 — Exercises

These exercises reinforce the two core skills from this module: capacity estimation (coding) and translating ambiguous requirements into a concrete design (design challenges).

## Coding Challenges

| Challenge | Description |
|---|---|
| [01 — Capacity Estimator](./coding-challenges/challenge-01/) | Implement a function that turns DAU, request size, and read/write ratio into QPS and storage estimates |

## Design Challenges

| Challenge | Description |
|---|---|
| [01 — Note-Taking App](./design-challenges/challenge-01.md) | Design a simple, non-distributed note-taking app — practice the full clarify → design → trade-off flow at small scale |
| [02 — NFR Document](./design-challenges/challenge-02.md) | Given a scenario, write a complete non-functional requirements document |

Work the coding challenge first — it's a direct, mechanical application of the [capacity estimation deep dive](../02-deep-dive/README.md). Then move to the design challenges, which are intentionally open-ended.
