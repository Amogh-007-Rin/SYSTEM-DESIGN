# Module 01 — Further Reading

- **Google SRE Book — "Service Level Objectives" chapter** (sre.google/sre-book/service-level-objectives) — the canonical reference for SLA/SLO/SLI definitions used throughout this repository.
- **"Numbers Everyone Should Know" — Jeff Dean, Google** — the original source of the latency numbers cheatsheet referenced throughout this repository; widely re-shared in system design talks and posts.
- **Martin Fowler — "Microservices" and "Monolith First"** (martinfowler.com) — foundational essays on when monolithic vs. distributed architecture makes sense, relevant to the "Types of Systems" section of this module.
- **"The Architecture of Open Source Applications"** (aosabook.org) — a free book of real engineers writing about the actual architecture of real systems; a good antidote to overly abstract system design content.
- **AWS Well-Architected Framework** (aws.amazon.com/architecture/well-architected) — a vendor-specific but broadly applicable framework for reasoning about the same properties (availability, reliability, performance) covered in this module.
