# Module 13 — Further Reading

- **"Brewer's CAP Theorem" — Julian Browne's retrospective, and Eric Brewer's own 2012 IEEE Computer retrospective "CAP Twelve Years Later: How the 'Rules' Have Changed"** — Brewer revisits his original 2000 PODC keynote conjecture in light of a decade of real-world systems, clarifying the nuances ("2 of 3" is a simplification) that the original talk didn't have space to spell out.
- **"Brewer's Conjecture and the Feasibility of Consistent, Available, Partition-Tolerant Web Services" (Gilbert & Lynch, 2002)** — the formal proof of the CAP theorem, published in *ACM SIGACT News*. This is the rigorous source behind the informal "pick two" framing everyone cites; worth reading once to see the actual formalism (atomic/sequential consistency, the asynchronous network model) behind the popular summary.
- **"Consistency Tradeoffs in Modern Distributed Database System Design" (Daniel Abadi, 2012)** — the paper that introduces PACELC, published in *IEEE Computer*. Directly extends CAP with the latency/consistency trade-off that exists even absent a partition; essential for understanding why CAP alone doesn't fully describe a system's behavior.
- **"In Search of an Understandable Consensus Algorithm (Extended Version)" (Diego Ongaro & John Ousterhout, 2014)** — the original Raft paper, from Stanford, published for USENIX ATC '14. Explicitly designed to be more approachable than Paxos; this is the primary source for everything in this module's Raft walkthrough (leader election, log replication, safety).
- **raft.github.io** — the official Raft project site, with the interactive visualization that animates leader election and log replication step by step. Built by the same research group; the single best resource for building visual intuition before or after reading the paper.
- **"Conflict-free Replicated Data Types" (Shapiro, Preguiça, Baquero, Zawirski, 2011)** — the foundational CRDT paper (INRIA research report), formally defining CRDTs and proving the convergence guarantees behind G-Counters, PN-Counters, G-Sets, and OR-Sets covered in this module's deep dive.
- **Apache ZooKeeper documentation — "ZooKeeper Internals" and the Zab protocol overview** (zookeeper.apache.org/doc) — the official documentation explaining ZooKeeper's consensus protocol and how it's used for coordination primitives like locks and leader election.
- **etcd documentation — "etcd and Raft"** (etcd.io/docs) — covers how etcd implements Raft in practice, including the parts (snapshotting, cluster membership changes) that the simplified election-only exercise in this module deliberately leaves out.
